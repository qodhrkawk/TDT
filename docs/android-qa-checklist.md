## 1. 드래그 순서 변경

- [ ] 할 일을 길게 누르면 말풍선이 들려 올라간다 (그림자/z-order)
- [x] [자동] 같은 날짜 안에서 위아래 이동, 놓으면 순서 유지
- [x] [자동] 다른 날짜 섹션으로 드래그 → 그 날짜로 변경 (유닛 테스트 + 스파이크)
- [x] [자동] 마지막 항목을 다른 날짜로 옮기면 빈 날짜 헤더 제거 (유닛 테스트)
- [ ] 드래그 후 위젯에 변경된 순서 반영
- [ ] 드래그 중 스와이프/탭 오발동 없음, 드래그 중 리스트 끝에서 자동 스크롤(미구현 — 긴 리스트에서 확인)

## 2. 고정 (접이식 스티키 바)

- [x] [자동] 길게 누르기 다이얼로그 "고정" → 헤더 아래 고정 바에 나타남 (최근 고정이 맨 위)
- [x] [자동] "고정됨 N" 탭 → 접힘/펼침
- [ ] 접힘 상태가 앱 재시작 후에도 유지
- [x] [자동] 고정 항목 길게 누르기 → 수정/삭제/고정 해제 다이얼로그
- [x] [자동] 고정 해제 → 원래 날짜 섹션 복귀, 섹션 없으면 날짜순 재생성 (유닛 테스트)

## iOS 실코드 기준 정합화 (2차 패스에서 반영)

handoff 문서만으로 만든 1차 구현이 실제 iOS와 달랐던 부분을 코드/스토리보드/에셋을 직접 읽어 맞췄다:

- 셀 **한 번 탭 → 메뉴** (더블탭 대기 포함), 길게 누르기는 드래그 전용. 메뉴는 하단 시트(고정/선택/수정/삭제 + 취소, 삭제 확인 "메모를 삭제할까요?", 인라인 편집 뷰)
- **아카이브는 왼쪽 페이지** ([아카이브, 메인], 시작은 메인 — iOS ControlPageViewController와 동일)
- 로고/아카이브/설정 타이틀·버튼 전부 **iOS 에셋 사용** (imgLogo·btnArchive·btnMain·btnMore·imgArchive·imgSettings·btnCloseSettings·btnSendInactive·icnDone·imgTheme3종·빈 상태 이미지·토스트 배경, template+tint 방식 동일)
- 리스트 **진입 슬라이드인** (메인: 오른쪽에서, 아카이브: 왼쪽에서, 0.1+0.05·섹션+0.02·행 지연)
- 아카이브 헤더 "날짜 + 한 일", 오늘 섹션 하이라이트, 오늘 항목 텍스트 mainText
- 탭 시 말풍선 하이라이트(archiveBox), 입력창 placeholder "해야 할 일을 입력해주세요.", 입력창 배경 boxColor 바
- 설정: 섹션 헤더(제목+부제), 화면 스타일 미리보기 이미지 행(h98), 테마 색 행(h48)+icn_done 체크, 슬라이드업 모달 + 닫기 버튼
- 고정 바: 헤더(핀+고정됨 N+셰브론, subText), 말풍선 테마색 1.0 테두리 + 내부 핀 아이콘
- 토스트 (imgToast 배경): 수정되었어요/삭제되었어요./이메일 주소를 복사했어요
- 가이드 3번 문구 iOS 원문 복원 ("한 번 클릭해서…")

여전히 다른 것 (의도/미완):
| 항목 | 비고 |
|---|---|
| 잠금화면 위젯 | 안드로이드 해당 없음 (handoff 5.1) |
| 위젯 디자인 | 기능은 동작하나 iOS FlickWidget 디자인과 정밀 대조 미완 |
| 추가 시 셀 상승 애니메이션(sendAnimation) | 미이식 |
