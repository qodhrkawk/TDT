# Flick 안드로이드 1.0 QA 체크리스트

`docs/3.0-qa-checklist.md`를 안드로이드용으로 변환. 실기기 권장 (위젯·제스처·IME).
[자동] = 에뮬레이터에서 이미 검증됨. 나머지는 실기기에서 확인 필요.

## 1. 드래그 순서 변경

- [ ] 할 일을 길게 누르면 말풍선이 들려 올라간다 (그림자/z-order)
- [x] [자동] 같은 날짜 안에서 위아래 이동, 놓으면 순서 유지
- [x] [자동] 다른 날짜 섹션으로 드래그 → 그 날짜로 변경 (유닛 테스트 + 스파이크)
- [x] [자동] 마지막 항목을 다른 날짜로 옮기면 빈 날짜 헤더 제거 (유닛 테스트)
- [ ] 드래그 후 위젯에 변경된 순서 반영
- [ ] 드래그 중 스와이프/탭 오발동 없음, 드래그 중 리스트 끝에서 자동 스크롤(미구현 — 긴 리스트에서 확인)

## 2. 고정 (접이식 스티키 바)

- [x] [자동] 길게 누르기 다이얼로그 "고정" → 헤더 아래 고정 바에 나타남 (최근 고정이 맨 위)
- [x] [자동] "고정됨 N" 탭 → 접힘/펼침
- [ ] 접힘 상태가 앱 재시작 후에도 유지
- [x] [자동] 고정 항목 길게 누르기 → 수정/삭제/고정 해제 다이얼로그
- [x] [자동] 고정 해제 → 원래 날짜 섹션 복귀, 섹션 없으면 날짜순 재생성 (유닛 테스트)
- [x] [자동] 고정 항목 왼쪽 스와이프 → 완료, 오늘 날짜 아카이브 (히트 영역 행 전체)
- [ ] 위젯에서 고정 항목이 항상 맨 앞 (오래된 메모여도)
- [ ] 키보드 열고 닫을 때 고정 바 겹침/여백 이상 없음

## 3. 일괄 선택

- [x] [자동] 다이얼로그 "선택" → 해당 항목 체크된 채로 선택 모드 시작
- [x] [자동] 행 어디를 탭해도 체크/해제 (더블탭 대기 없음)
- [x] [자동] 하단 바 "취소 | 완료 N | 삭제 N"
- [x] [자동] 일괄 완료 → 아카이브 오늘 날짜
- [ ] 일괄 삭제 → 확인창 1회 → 삭제
- [ ] 선택 모드 중 스와이프/더블탭/드래그 비활성
- [ ] 여러 날짜에 걸쳐 선택 → 처리 후 빈 섹션 정리 (유닛 테스트로는 검증됨)

## 4. 스와이프 완료

- [ ] 왼쪽 스와이프 완료 체감 ~0.3초 + 우측 그라데이션
- [ ] 연속으로 빠르게 여러 개 스와이프해도 엉뚱한 항목이 지워지지 않음 (id 기반이라 구조적으로 안전하지만 실기기 확인)
- [x] [자동] 아카이브 왼쪽 스와이프 복원 → 원래 날짜 섹션으로
- [ ] 스와이프 도중 같은 항목 재스와이프 중복 처리 없음

## 5. 실행 시 오늘로 자동 스크롤

- [x] [자동] 실행 → 오늘 섹션 위치
- [ ] 데이터 많을 때(수백 개) 첫 프레임 확인 — scrollToItem 2회 보정 동작
- [ ] 고정 바 + 오늘 할 일이 첫 화면에 함께 보임

## 6. 위젯

- [x] [자동] 홈 위젯 배치 → 내용 정상 렌더 (고정 우선 + 최근)
- [ ] "Flick 오늘" 위젯 배치 → 오늘 항목만 표시
- [ ] 중형 5줄 / 대형 10줄 분기 (위젯 리사이즈로 확인 — 기준값 220dp 튜닝 여지)
- [ ] 화면 스타일 강제(라이트/다크)가 위젯 배경·텍스트에 반영 (시스템 다크와 다르게 설정해 확인)
- [x] [자동] 할 일 추가/완료/삭제/드래그 시 위젯 데이터 갱신
- [ ] 재부팅 직후 위젯 확인: 빈 상태 고착 없음 (읽기 실패 시 캐시 유지 로직)
- [ ] 빈 상태 문구 "할 일을 모두 완료했어요!"
