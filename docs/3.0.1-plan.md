# Flick 3.0.1 계획

확정일: 2026-08-26 / 기준: 3.0.0 심사 제출 상태 (main `d885f30`)

3.0 출시 직후의 가벼운 후속 패치. 데이터 모델 변경 없음, 서버 없음. 리뷰 요청이 계속 반영되고 있다는 신호를 빠르게 주는 것이 목적. 출시 후 리뷰·크래시 모니터링에서 급한 것이 나오면 그것이 최우선으로 끼어든다.

---

## 스코프 (3개)

### 1. 소형(1:1) 홈 위젯

리뷰 근거: "위젯 크기 젤 작은 거 정사각형 되게 해주세여", "위젯크기가 커서 1:1 사이즈로 줄여주세요" 등 5건 (`appstore-reviews-raw.md`)

- `FlickWidget`의 `supportedFamilies`에 `.systemSmall` 추가.
- 구성은 **잠금화면 위젯(accessoryRectangular)과 동일하게 최근 항목 3개** — 좁은 공간이므로 고정 우선 규칙 대신 잠금화면과 같은 단순 구성을 따른다.
- 스타일은 홈 위젯 규칙: 앱 배경색, 화면 스타일(라이트/다크 강제) 추종, 중요 표시 점은 테마색.
- 빈 상태 문구는 기존과 동일 ("할 일을 모두 완료했어요!").

### 2. 작성 중 줄바꿈

리뷰 근거: P3 "작성 중 줄바꿈" (`3.0-improvement-plan.md`)

- 현재 상태: 수정 다이얼로그는 `UITextView`라 이미 여러 줄 입력 가능. 셀 표시도 줄바꿈 지원. **메인 입력창만 `UITextField`(한 줄)라 줄바꿈이 불가능.**
- 메인 입력창을 여러 줄 입력으로 교체 (`UITextView` 기반, 내용에 따라 높이 자동 확장, 최대 높이 제한 후 스크롤).
- 리턴 키 = 줄바꿈, **전송은 전송 버튼으로만** (수정 다이얼로그와 동일한 감각).
- 주의: 키보드 애니메이션(입력 영역 상승)과 높이 확장이 겹치므로 레이아웃 회귀 테스트 필요. 일괄 선택 모드 바 전환도 동일하게 동작해야 함.

### 3. 링크 인식

리뷰 근거: P3 "꾹 눌러 복사 + 하이퍼링크 인식" (카톡 메모 대체 유저층)

- "꾹 눌러 복사"는 길게 누르기가 이미 다이얼로그(수정/삭제/고정/선택)에 배정되어 있어 제스처가 겹치므로 **하지 않는다.** 대신:
- 메모 텍스트에서 URL 감지 (`NSDataDetector`, http/https).
- **표시**: 링크 부분만 파란색 하이퍼링크 UI (밑줄 포함, 라이트/다크 각각 가독성 확인). 셀 라벨을 attributed text로 전환.
- **동작**: 링크가 포함된 메모를 길게 누르면 기존 다이얼로그에 **"링크 열기" 선택지 추가** → 사파리로 이동. 링크가 여러 개면 첫 번째 링크를 연다 (단순하게 시작, 요청 들어오면 목록화).
- 적용 범위: 메인 셀 + 아카이브 셀 + 고정 바. 위젯은 표시만 (탭 동작 없음, 이번 스코프 제외).
- 주의: 더블탭(중요 표시)·스와이프와 충돌하지 않도록 라벨 자체에는 탭 핸들러를 달지 않는다. 링크 열기는 다이얼로그를 통해서만.

## 하지 않는 것

- 꾹 눌러 복사 — 제스처 충돌로 제외 (위 3번 참고)
- 테마 색상 ↔ 위젯 색상 연동 — **이미 구현되어 있음** (`WidgetTodoRow.swift`, `FlickLargeWidgetView.swift` 등에서 ThemeManager 사용, 테마 변경 시 위젯 리로드 포함). 리뷰가 2.0.2 시절 것이라 목록에 남아 있었을 뿐.
- 폰트/글씨 크기, 날짜 지정, carry-over, iCloud — 3.1(Flick Pro) 스코프
