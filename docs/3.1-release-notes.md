기기를 옮길 때 쓸 수 있는 기능을 담았어요.

- 데이터 내보내기·가져오기: 설정에서 할 일을 파일로 저장하고, 다른 기기에서 합칠 수 있어요.
- 내용 없이 공백이나 줄바꿈만 있는 메모가 저장되지 않게 했어요.
- 여러 줄을 입력할 때 목록 아래쪽이 가려지지 않게 했어요.
- 링크 바로 뒤에 붙은 글자(예: "~에서")까지 링크로 잡혀 열리지 않던 문제를 고쳤어요.
- 오늘 완료한 메모의 링크가 아카이브에서 파란색으로 보이지 않던 문제를 고쳤어요.
- 고정 목록의 접기·펼치기 화살표가 보이지 않던 문제를 고쳤어요.
- 안내 정정: 메모를 탭한 뒤 '링크 열기'를 누르면 바로 열 수 있어요.

리뷰로 의견 남겨주신 모든 분들께 감사드려요. 계속 업데이트할게요.
