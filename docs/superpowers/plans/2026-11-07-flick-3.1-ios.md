# Flick 3.1 iOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iOS 앱에 JSON 파일 내보내기/가져오기를 추가하고, 빈 메모와 입력창 가림 버그를 고쳐 3.1.0으로 올린다.

**Architecture:** 파일 형식과 합치기는 UIKit 없는 순수 Swift 값 타입으로 만들어 `swiftc` 테스트로 검증한다. `TodoStore`는 현재 데이터를 값으로 내주고 합친 결과를 한 번에 저장한다. 설정 화면은 공유·파일 선택 UI만 맡고, 가져온 뒤 알림으로 메인과 아카이브를 갱신한다.

**Tech Stack:** Swift, UIKit, Foundation `JSONEncoder`/`JSONDecoder`, `UIActivityViewController`, `UIDocumentPickerViewController`

**Spec:** `docs/superpowers/specs/2026-11-07-flick-3.1-data-transfer-design.md`

**범위 밖:** 안드로이드 구현은 별도 계획으로 작성한다. App Store 제출은 사람이 한다.

- [ ] **Step 6: `String.isBlank`와 `FlickBackup.swift` 구현**

- `isBlank`는 `trimmingCharacters(in: .whitespacesAndNewlines).isEmpty`.
- `parse`는 먼저 `format`과 `version`만 읽는다. `format` 불일치나 `version < 1`은 `invalidFile`, `version > currentVersion`은 `newerVersion`. 그 뒤 전체를 디코딩하고 모든 날짜와 메모를 검증한다. 디코딩 오류는 `invalidFile`로 바꾼다.
- `isValidDate`는 정규식 `^\d{4}\.\d{2}\.\d{2}$`.
- `exportData`는 `.prettyPrinted`, `.sortedKeys`, `.withoutEscapingSlashes`로 쓰고, `exportedAt`은 `ISO8601DateFormatter`, `source.platform`은 `"ios"`.
- `fileName`은 `en_US_POSIX` 로케일의 `yyyy-MM-dd` 형식.

`guideTexts`는 다음 세 문구다.

- `두 번 탭해서 중요 표시를 해 보세요.`
- `한 번 클릭해서 메모를 삭제하거나 수정할 수 있어요.`
