# Flick 3.0 개선사항 정리

앱스토어 공개 리뷰 전체(50개, 2026-07-12 수집, `appstore-reviews-raw.md`) 분석 결과.
평점 분포: ★5 42개 / ★4 6개 / ★3 2개 — 만족도는 매우 높고, 불만은 대부분 "기능이 없어서"가 아니라 "이것만 있으면 완벽"류의 요청.

## P0 — 버그 (3.0 이전에라도 고쳐야 함)

| # | 항목 | 언급 수 | 내용 |
|---|------|--------|------|
| 1 | 위젯 "할 일을 모두 완료했어요!" 고착 버그 | 6 | iOS 17.4 이후 위젯에 할 일 목록이 안 뜨고 완료 메시지만 표시. 재부팅하면 일시적으로 복구. 2.0.2가 위젯 버그 수정 릴리스였는데 이후 OS 업데이트로 재발한 것으로 보임. 최다 신고 버그. |
| 2 | 문의 메일 발송 실패 | 1 | "문의하고 싶어도 메일이 보내지지 않는다" — 지원 채널이 막혀 있어 버그 신고가 리뷰로만 들어오는 상태. |
| 3 | 스와이프 삭제 딜레이 | 1 | 슬라이드 후 삭제 확정까지 텀이 길어 연속 삭제 시 다른 항목이 지워짐. |
| 4 | 쌍자음 입력 문제 | 1 | 입력 중 쌍자음이 안 된다는 신고 (재현 확인 필요). |

## P1 — 핵심 기능 요청 (3.0 메인 테마 후보)

| # | 항목 | 언급 수 | 내용 |
|---|------|--------|------|
| 1 | 할 일 순서 변경 (드래그 / 길게 눌러 이동) | 10+ | 압도적 1위 요청. "삭제하고 다시 쓰는 걸 반복한다"는 유저 다수. 상단 고정(핀) 요청도 1건 포함. |
| 2 | 기기 간 연동 (iCloud) + 아이패드/맥 지원 | 6 | "유료여도 결제하겠다"는 리뷰 다수. 백업 요청(1건)도 사실상 같은 니즈. |
| 3 | 위젯 개선: 1:1 소형 위젯 + 잠금화면 위젯 | 5 | 현재 위젯이 커서 부담된다는 의견. 잠금화면(Lock Screen) 위젯 요청 포함. |
| 4 | 날짜 지정: 다른 날짜에 할 일 추가 / 반복 할 일 | 4 | 현재는 당일 추가만 가능. 스토어 스크린샷을 보고 날짜 지정이 되는 줄 알았다는 유저도 있음. |

## P2 — 그다음 우선순위

| # | 항목 | 언급 수 | 내용 |
|---|------|--------|------|
| 1 | 폰트: 시스템 글꼴 옵션, 폰트 추가, 위젯 폰트/글씨 크기 조절 | 5 | 본문·위젯 모두. 글씨 크기 3단계 조절 요청 포함. |
| 2 | 못 한 일 다음날 자동 미루기 (carry-over) | 2 | "P를 위한 앱"이라는 정체성과 잘 맞는 기능. 매일 다시 적는 게 가장 큰 불편. |
| 3 | 일괄 삭제 / 전체 삭제 (다중 선택) | 2 | 기록이 쌓일수록 하나씩 스와이프 삭제가 고통. ★3 리뷰의 주 원인. |
| 4 | 박스/테두리 색상 추가 (커스텀 컬러) | 2 | 리스트가 늘어나면서 구분용 색상이 부족. |

## P3 — 소수 의견이지만 검토 가치

- 꾹 눌러 복사 (아카이브 항목 포함) + 하이퍼링크 인식 — 카톡 메모 대체 유저층의 요청
- 스와이프로 수정 진입 (현재 수정 UX가 숨어 있음)
- 작성 중 줄바꿈
- 위젯 할 일 정렬 옵션 (등록순 표시)
- 테마 색상과 위젯 색상 연동
- 빈 상태 문구 커스텀 ("해야 할 일을 입력해주세요" → 메모/일기 용도로 쓰는 유저가 직접 설정)
- 카테고리/챕터 분류
- 애플워치 지원
- 안드로이드 버전 (3건) / 윈도우 (1건) — 플랫폼 확장이라 3.0 범위 밖 참고용

## 수익화 시그널

"유료여도 산다", "인앱 결제 의사 있다"는 리뷰가 4건. 특히 **iCloud 연동 + 아이패드 지원**을 유료 기능으로 언급한 유저가 있음 → 3.0에서 프리미엄 티어(동기화·폰트·컬러 팩) 검토 여지.

## 요약: 3.0 추천 스코프

1. **위젯 버그 근본 수정** (P0-1) — 신뢰 회복이 최우선, 리뷰 답글로 수정 사실 알리기
2. **순서 변경** (P1-1) — 최다 요청, 구현 비용 대비 임팩트 최대
3. **iCloud 동기화 + 아이패드(유니버설) 지원** (P1-2) — 3.0의 간판 기능이자 수익화 축
4. **소형·잠금화면 위젯** (P1-3) + 위젯 리팩토링과 함께 진행
5. **날짜 지정 + 자동 미루기** (P1-4, P2-2) — "계획 없는 사람들의 투두"라는 앱 정체성 강화
6. 지원 메일 링크 수리 (P0-2)
