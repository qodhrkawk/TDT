# Flick 3.0 QA 체크리스트

대상 빌드: main (`4d5c358`) / 실기기 권장 (위젯·제스처는 시뮬레이터로 검증 불가한 항목 있음)

## 1. 드래그 순서 변경 (신규)

- [ ] 할 일을 길게 누르면 **말풍선만** 들려 올라간다 (셀 전체/배경이 아니라)
- [ ] 같은 날짜 안에서 위아래로 이동, 놓으면 순서 유지
- [ ] 다른 날짜 섹션으로 드래그 → 그 날짜로 이동 (앱 재시작 후에도 유지)
- [ ] 어떤 날짜의 마지막 항목을 다른 날짜로 옮기면 빈 날짜 헤더가 사라진다
- [ ] 드래그 후 위젯에 변경된 순서 반영
- [ ] 드래그 중 스와이프/탭이 오발동하지 않는다

## 2. 고정 (신규 — 접이식 스티키 바)

- [ ] 할 일 탭 → 다이얼로그에 "고정" 버튼 → 고정하면 헤더 아래 고정 바에 나타남
- [ ] 고정 바는 **스크롤과 무관하게 항상 보인다** (리스트가 바 아래로 지나가며 가려짐, 비침 없음)
- [ ] "고정됨 N" 헤더 탭 → 접힘/펼침. 앱 재시작 후에도 접힘 상태 유지
- [ ] 고정 항목 탭 → 수정/삭제/"고정 해제" 다이얼로그
- [ ] 고정 해제 → 원래 날짜 섹션으로 복귀 (그 날짜 섹션이 사라졌으면 날짜순 위치에 재생성)
- [ ] 고정 항목 왼쪽 스와이프 → 일반 항목과 같은 감각/그라데이션으로 완료 처리, 오늘 날짜 아카이브에 들어감
- [ ] 고정 스와이프 히트 영역이 행 전체(좌우 꽉 참) — 말풍선 오른쪽 빈 곳에서도 동작
- [ ] 위젯에서 고정 항목이 항상 맨 앞에 노출 (오래된 메모여도)
- [ ] 키보드 열고 닫을 때 고정 바 겹침/여백 이상 없음

## 3. 일괄 선택 (신규)

- [ ] 할 일 탭 → 다이얼로그(고정/선택/수정/삭제)에서 "선택" → 그 항목이 체크된 채로 선택 모드 시작
- [ ] 상단 더보기(⋯)는 기존처럼 설정이 바로 열림
- [ ] 선택 모드: 행 어디를 탭해도(체크 아이콘 포함) 즉시 체크/해제, 빠른 연속 탭도 씹힘 없음
- [ ] 미선택 말풍선의 밝기 변화 없음 — 상태는 체크 아이콘으로만 표시
- [ ] 하단 바에 "완료 N / 삭제 N" 카운트
- [ ] 일괄 완료 → 아카이브 오늘 날짜에 들어감 + 토스트
- [ ] 일괄 삭제 → 확인창 → 삭제 + 토스트
- [ ] 선택 모드 중 스와이프/더블탭/드래그 비활성
- [ ] 취소로 나오면 원상 복구
- [ ] 여러 날짜에 걸쳐 선택 → 일괄 처리 후 빈 날짜 섹션 정리

## 4. 스와이프 완료 개선 (변경)

- [ ] 왼쪽 스와이프 완료가 이전보다 빠름 (~0.3초)
- [ ] **연속으로 빠르게 여러 개 스와이프해도 엉뚱한 항목이 지워지지 않음** (핵심 버그 수정 검증)
- [ ] 아카이브에서 오른쪽 스와이프(복원)도 동일하게 동작
- [ ] 스와이프 도중 같은 항목 재스와이프해도 중복 처리 없음

## 5. 실행 시 오늘로 자동 스크롤 (신규)

- [ ] 데이터가 많을 때 앱 실행 → 스크롤 없이 바로 오늘(맨 아래) 위치
- [ ] 고정 바가 있으면 첫 화면 = 고정 메모 + 오늘 할 일

## 6. 위젯 (P0 버그 수정 + containerBackground)

- [ ] 홈 중형/대형 위젯, 오늘 위젯, 잠금화면 위젯 모두 **내용이 정상 표시** ("Please adopt..." 문구 없음)
- [ ] 홈 위젯 배경이 앱 배경색과 동일
- [ ] **재부팅 → 잠금 해제 전 잠시 대기 → 위젯 확인**: "할 일을 모두 완료했어요!" 고착 없음 (재발 시 15분 내 자가 복구되는지도 확인)
- [ ] 할 일 추가/완료/삭제 시 위젯 갱신
