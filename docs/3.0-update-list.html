위젯 "할 일을 모두 완료했어요!" 고착 버그

iOS 17.4 이후 위젯에 할 일이 있어도 완료 메시지만 표시. 재부팅 시 일시 복구. 최다 신고 버그이며 위젯이 앱의 핵심 가치라는 점에서 최우선.

신고 6건

문의 메일 발송 실패

"문의하고 싶어도 메일이 안 보내진다" — 지원 채널이 막혀 버그 신고가 리뷰로만 유입되는 상태. mailto 링크·지원 이메일 점검.

신고 1건

스와이프 삭제 딜레이로 인한 오삭제

삭제 확정까지 텀이 길어 연속 삭제 시 의도치 않은 항목이 지워짐. 애니메이션·확정 타이밍 재조정.

신고 1건

쌍자음 입력 문제

입력 중 쌍자음이 씹힌다는 신고. 텍스트필드 입력 처리 재현 확인 필요.

신고 1건
P1

핵심 기능 — 3.0 간판

요청 빈도와 임팩트가 가장 큰 기능

할 일 순서 변경 — 드래그 & 길게 눌러 이동

압도적 1위 요청. "순서 바꾸려고 삭제 후 다시 쓴다"는 유저 다수. 상단 고정(핀) 요청 포함. 구현 비용 대비 임팩트 최대.

요청 10건+

iCloud 동기화 + 아이패드 지원

"유료여도 산다"는 리뷰가 나온 유일한 기능군. 백업 요청도 같은 니즈. 유니버설 앱 전환 + CloudKit 동기화 — 3.0 수익화의 축.

요청 6건

위젯 라인업 확장 — 1:1 소형 + 잠금화면

"위젯이 커서 부담"이라는 의견 다수. 소형(systemSmall) 위젯과 잠금화면 위젯 추가. 위젯 버그 수정과 묶어 위젯 스택 전면 리팩토링.

요청 5건

날짜 지정 — 다른 날에 할 일 추가 · 반복

현재는 당일 추가만 가능. 미래 날짜에 할 일 등록과 반복 할 일 요청. 스토어 스크린샷을 보고 되는 줄 알았다는 유저도 있어 기대 격차 존재.
