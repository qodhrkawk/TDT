# Flick 3.0 릴리스 노트

## 앱스토어 "새로운 기능" (제출용 초안)

```
3년 만에 돌아온 플릭, 가장 많이 요청해주신 기능들을 담았어요.

- 순서 변경: 할 일을 길게 눌러 원하는 위치로 옮겨보세요. 다른 날짜로도 옮길 수 있어요.
- 고정: 자주 봐야 하는 메모를 위에 고정해두세요. 스크롤해도, 위젯에서도 항상 보여요.
- 한 번에 정리: 여러 개를 선택해서 한 번에 완료하거나 삭제할 수 있어요.
- 위젯 수정: 재부팅 후 위젯에 "할 일을 모두 완료했어요!"만 표시되던 문제를 해결했어요.
- 완료 스와이프가 더 빨라졌고, 연속으로 밀 때 다른 항목이 지워지던 문제를 고쳤어요.
- 앱을 열면 바로 오늘 할 일이 보여요.
- 1:1 문의하기가 동작하지 않던 문제를 해결했어요.

리뷰로 의견 남겨주신 모든 분들께 감사드려요. 계속 업데이트할게요.
```

## 제출 전 체크리스트

1. **실기기 업그레이드 테스트** — 앱스토어 2.0.2 설치 → 데이터 생성 → Xcode로 3.0 덮어쓰기 → 할 일/아카이브/테마 보존 확인
2. **실기기 위젯 테스트** — 위젯 추가 → 재부팅 → 잠금 해제 전 잠시 대기 → 위젯에 할 일 표시 확인
3. 제스처 감 확인 — 드래그, 고정 스와이프, 일괄 선택
4. Xcode Archive (Release) → TestFlight 업로드
5. App Store Connect: 스크린샷 갱신(고정 바 등 UI 변경), 릴리스 노트 입력, 심사 제출
6. 출시 후: 위젯 버그 신고 리뷰들에 답글로 수정 사실 알리기 (리뷰 회복의 핵심)
```
