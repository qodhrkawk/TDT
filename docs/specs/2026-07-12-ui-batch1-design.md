# Flick 3.0 — UI 배치 1 설계

승인일: 2026-07-12 / 브랜치: `feature/3.0-ui-batch1` (base: `Widget_Refactoring`)

## 범위

서버 없이 UI/로컬 데이터만으로 가능한 4개 기능:

1. 할 일 순서 변경 — 길게 눌러 드래그, 날짜 섹션 간 이동 허용 (이동 시 해당 날짜로 변경)
2. 스와이프 완료 애니메이션 단축 + 셀 재사용 stale indexPath 오삭제 버그 수정
3. 상단 고정(핀) — 섹션 내 최상단 고정, 기존 수정/삭제 다이얼로그에 토글 추가
4. 일괄 선택 — 다중 선택 후 일괄 완료(아카이브)/일괄 삭제

## 데이터 모델

- `TodoData`에 `isPinned: Bool` 추가. 구버전 데이터 하위 호환: `decodeIfPresent ?? false`.
- 순서는 배열 순서가 곧 표시 순서 (기존 구조 유지, 별도 정렬 필드 없음).
- 앱·위젯 타겟이 같은 모델을 공유하므로 양쪽 모두 호환 디코딩 적용.

## 구조 변경

- `TodoStore` 신설: `[[TodoData]] + dateInfo` 동시 변형 로직(이동, 날짜 변경, 핀 정렬, 일괄 처리, 빈 섹션 제거, 로드/저장)을 `TodoViewController`에서 분리. 단위 테스트 대상.
- 뷰 컨트롤러는 TodoStore 호출 + 테이블뷰 갱신만 담당.

## 기능별 설계

### 드래그 순서 변경
- `UITableViewDragDelegate`/`UITableViewDropDelegate`, `dragInteractionEnabled = true`.
- 섹션 간 드롭 시 `todo.date = 대상 섹션 날짜`. 핀 그룹 위로 드롭하면 핀 그룹 바로 아래로 클램프.
- 이동 완료 시 저장 + 위젯 갱신 1회.

### 스와이프 개선
- 3단계 애니메이션(~1초) → 단일 슬라이드아웃(~0.3초).
- 버그 수정: 삭제 시 셀에 저장된 `myIndexpath` 대신 완료 시점에 `tableView.indexPath(for: cell)`로 재조회.

### 핀
- 섹션 정렬 규칙: 핀(고정 순) → 일반(입력 순).
- 셀에 핀 인디케이터 표시 — 에셋/CoreGraphics로 그림, 이모지 금지.
- 토글: AlertViewController에 "고정/고정 해제" 액션 추가.

### 일괄 선택
- "선택" 버튼 → 선택 모드 → 셀 탭으로 토글 → 하단 액션 바(일괄 완료 / 일괄 삭제).
- 삭제는 확인 알럿 1회. 선택 모드 중 스와이프/드래그/더블탭 비활성화. 처리 후 위젯 갱신 1회.

## 테스트

- TodoStore 단위 테스트: 섹션 내/간 이동, 날짜 변경, 핀 정렬·클램프, 일괄 완료/삭제, 빈 섹션 제거, 구버전 데이터 디코딩.
- 시뮬레이터 수동 검증. iOS 12 타겟이 현 Xcode에서 빌드 안 되면 타겟 상향을 별도 제안.
